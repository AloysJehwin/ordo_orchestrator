# Glossary

| Term | Meaning |
| --- | --- |
| Access level | What a member sees, 1 to 4: stages and status, plus outcomes, plus proofs and measurements, everything; set per role or per person, with a line and stage scope |
| AOI | Automated optical inspection |
| Case | A tester's signed claim that a validator selected the wrong proof of work, with a proposed cut of the validator's stake; a manager who is neither party upholds or rejects it |
| CMM | Coordinate measuring machine |
| Contributor | A member who joined an org (openly, by default) and submits proof of work on stages; level 2 by default |
| Cpk | Process capability index; ≥ 1.33 is a common minimum |
| Gate | A stop point in a run that needs a human release |
| Genealogy | The record of which input lots produced which output lots |
| Manager | The role with every right in an org: pipelines, autonomy, agents and wallets, approvals, cases, rewards; always level 4 |
| OEE | Overall equipment effectiveness: availability × performance × quality |
| Proof of work | A contributor's signed record of what they did on a stage and measured, gathered by the `ordo-pow` terminal agent through the 0G Private Computer Router; values are committed, never published |
| Rolled yield | Product of the yields of all completed stages |
| Selection | A staked validator's signed choice of the valid proof of work for a stage; it closes the stage and, with OrdoTrust v3, pays a reward and a fee |
| Takt | Available time divided by demand; the required pace per unit |
| TEE | Trusted execution environment: hardware that runs a model so that its operator cannot see the conversation |
| Tester | A member who stakes and opens cases against validators; level 3 by default |
| UNS | Unified Namespace: a shared, event-driven model of plant data, usually over MQTT |
| Validation package | Formal record of scope, checks, evidence and signatures proving a stage or change works |
| Validator | A member who stakes, selects the valid proof of work for a stage and reviews validation packages; level 3 by default |
